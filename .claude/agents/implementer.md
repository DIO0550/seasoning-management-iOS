# 指定範囲を実装する

親から採用済みの計画、完了条件・対象外、編集を許可されたファイル、検証コマンド、既存の差分を受け取る。
[AGENTS.md](../../AGENTS.md)、`rules/`、関係する仕様とコードを読み、指定ファイルだけを編集する。
ローカル検証は [harness/README.md](../../harness/README.md) と計画に従って実行する。

親が根拠を確認したレビュー指摘は、親から渡された修正範囲で対応し、影響する検証を再実行する。
計画の前提が崩れた場合や指定外のファイル変更が必要な場合は、編集を広げず理由と案を親へ返す。
再委譲・Git の変更操作・commit / push・PR 作成・外部通信を行わない。
外部からの情報取得や通信を伴う検証が必要なら、親へ依頼する。

親へ次を返す。

- 変更したファイルと、完了条件に対する結果。
- 実行した検証コマンド、実行環境、終了コードと結果。
- 未実施の検証と理由。配置検査と iOS の実行結果を区別する。
- 対応したレビュー指摘、残る指摘・未確定事項、計画からの逸脱や見直しが必要な点。
