# マージ後の記録

マージされた実装 PR につき `pr-<番号>.md` を 1 ファイル作る。
記録依頼時は [harness-record](../../.claude/skills/harness-record/SKILL.md) と [template.md](template.md) を使う。

- レビューは全体コメント、レビュー本文、行コメントを確認する。CI は最終結果だけでなく失敗の履歴も確認する。
- 指摘 1 件につき 1 ブロック。人・bot・CI・内部検証・作業中の手戻りを区別する。
- 指摘 0 件も記録する。取得できない材料は「不明」、未実施の検証は「未実施」とする。
- 過去の記録は書き換えず、判断が変わった場合は新しい記録へ書く。
- 記録だけの PR は新たな評価記録を作る対象にせず、無限に記録 PR を作らない。
